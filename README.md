# nih-industries/tap

Homebrew formulae and casks for my projects.

Homebrew only loads formulae and casks from taps you trust, so trust this
one first:

```sh
brew trust nih-industries/tap
```

Then install whatever you like:

```sh
brew install nih-industries/tap/booksmart
brew install nih-industries/tap/cardthing
brew install nih-industries/tap/very-normal
brew install nih-industries/tap/world-txt
brew install --cask nih-industries/tap/adequate
brew install --cask nih-industries/tap/font-mote-mono
```
